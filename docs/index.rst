.. topic:: Preface

   GUIs, RFI checkers, receiver monitors, backends, and meteo services
   all require access to certain antenna parameters, such as the current
   azimuth and elevation, device temperatures, configurations,
   LO frequencies, and more.  This documentation explains how to
   easily retrieve these parameters using an application called Suricate,
   which is composed of three packages: :ref:`api`, :ref:`monitor`,
   and :ref:`alarms`. Each package is covered in a dedicated chapter.
